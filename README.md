# EEG Motor Imagery Classification

A deep learning pipeline for classifying EEG motor movement/imagery signals using convolutional neural networks, EEGNet, and CSP-based spatial filtering.

## Dataset

The EEG data used in this project is publicly available through PhysioNet:

[EEG Motor Movement/Imagery Dataset](https://physionet.org/content/eegmmidb/1.0.0/#files-panel)

## Research Report

[Final Research Report](./EEG%20Research%20Report.pdf)

## Models

- Basic MLP
- Raw EEG CNN
- EEGNet
- CSP-enhanced CNN
- CNN/EEGNet ensemble

The final ensemble achieved approximately 75% test accuracy.
